STICKER IMAGE GENERATION PROMPT — terra-yank
=======================================

PROJECT CONTEXT
---------------
This sticker is for a developer tool called "terra-yank" (pronounced "I to C V2", short for
"TerraYank"). It is a web application built for cloud
engineers who manage cloud infrastructure on cloud platform (Government Commercial Cloud) — Singapore's
sovereign cloud environment built on AWS.

THE CORE PROBLEM IT SOLVES
---------------------------
Government engineers often build AWS cloud infrastructure manually (clicking around in the AWS
Console) instead of writing code. This "ClickOps" approach leaves infrastructure ungoverned,
undocumented, and impossible to audit or replicate. terra-yank fixes this: it scans your AWS account,
finds everything that isn't tracked in code, and uses an AI agent to automatically write the
Terraform code that describes those resources — so engineers can finally bring their infrastructure
under version control in GitLab.

WHAT THE TOOL ACTUALLY DOES (the magic)
----------------------------------------
1. Connects to your AWS account and discovers every cloud resource (EC2, S3, Lambda, RDS,
   VPCs, IAM roles, etc.) using AWS Resource Explorer.
2. Compares discovered resources against uploaded Terraform state files to classify what's
   already managed vs what's rogue/unmanaged.
3. Separates platform-owned baseline infrastructure (platform-tagged) from your team's
   own resources.
4. You select the unmanaged resources you want to bring under code.
5. The tool spins up a temporary Terraform workspace, runs "terraform plan -generate-config-out"
   to auto-generate initial Terraform config from live cloud state.
6. An AI agent (Claude by Anthropic) iteratively refines the generated Terraform code —
   removing defaults, grouping resources by service, extracting variables — and validates
   each iteration by running "terraform plan" until the plan is perfectly clean (zero drift).
7. You review the generated .tf files live in the browser while watching real-time AI progress.
8. One click commits the production-ready Terraform files into your GitLab repository.

KEY TECHNOLOGIES IN THE STACK
------------------------------
- Node.js backend (Express)
- AWS Resource Explorer 2 (discovery engine)
- Terraform CLI (bundled inside the Docker container, v1.12.1)
- Anthropic Claude AI (the LLM that writes and refines Terraform code)
- GitLab API (GitLab instance)
- OAuth provider (SSO)
- Deployed via Docker
- Docker container
- SQLite database
